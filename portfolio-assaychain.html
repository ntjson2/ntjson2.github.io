What it does

AssayChain is a production AI system that turns unstructured assay reports — fire-assay PDFs, lab certificate images, CSV data tables, or plain text — into structured, quality-graded JSON. Every response is on-chain verifiable via IPFS + EAS attestation, and it's agent-payable via x402 (USDC on Base).

The AI extraction & grading pipeline

The core of the product is not a black box — it's an honest, self-checking extraction pipeline. Each extraction is scored on four signals:

  • Structural validity — did the model produce valid sample rows?
  • Coverage — did it find at least 70% of the expected rows?
  • Self-consistency — does a second independent extraction pass return the same numbers?
  • Cross-check — are element symbols and units recognized and within physical bounds?

That produces an A–D grade: Grade A = all four pass; B = three; C = two; D = one or fewer. Rather than overselling results, the system gives an 80% refund on Grade D and flags Grade C for manual review. This is evaluation rigor as a product feature — exactly the kind of honesty that makes AI trustworthy.

Data safety & privacy

Site coordinates in extraction results are rounded to ±0.1° before storage and delivery — enough precision for regional analysis, not enough to expose a specific claim. Email addresses and phone numbers in document text are stripped and replaced with [REDACTED] tokens before anything reaches the API response.

Built for AI agents

  • MCP endpoint — usable from Claude, Cursor, VS Code / GitHub Copilot, Windsurf, and any MCP SDK client.
  • REST + MCP — the output schema matches the benchmark endpoints, so an AI agent can consume both with no remapping.
  • x402 agent payments — machines pay per call with USDC on Base via EIP-3009; no API key needed, credit card for humans.
  • On-chain provenance — every response carries an attestation_uid and ipfs_cid you can verify yourself.
