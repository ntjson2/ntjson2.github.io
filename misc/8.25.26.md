Status: Complete (built 2026-08-23). This paper is written to be lifted straight into a resume,

It is intentionally honest: it sells the methodology and honesty, not inflated accuracy.

## 1. TL;DR (the portfolio blurb)

> I designed, built, and honestly evaluated a **mineral prospectivity model** - a machine-learning
> system that predicts, for any point on a map, which of five metals (gold, silver, copper, lead,
> zinc) are most likely to occur there, based on rock type, deposit type, and location. Trained on
> 182 schema-locked, EAS-attested mining districts plus the USGS MRDS dataset, it uses strict
> leave-one-state-out spatial cross-validation and calibrated probabilities. Rather than oversell it,
> I published exactly where it does and does not generalize - the gold model predicts with F1 0.87
> in-region, and I documented the honest out-of-region limits.

---

## 2. What it does (plain English)

> Imagine you point to any spot on a map - say, somewhere in Nevada - and describe the rocks there
> (granite? volcanic? limestone?) and whether it has been mined before. The model looks back at the
> mining districts it already knows - places where we do know what metals were found - and answers:
> "New spots that look like this one, in this part of the country, with this kind of rock, usually
> turn out to have gold, sometimes silver and copper, rarely zinc." It returns a score from 0 to 1
> for each of five metals. It is pattern-matching, not magic - it learned the patterns from past
> districts, not from digging.

---

## 3. The problem it solves

Junior miners and exploration consultancies face a screening question every day: "Where should we
look next, and for what?" That answer is usually someone's gut feel or a rule of thumb. A transparent,
data-driven prioritization tool - one that also cites its supporting, on-chain-attested reference
districts - turns that gut feel into a repeatable, auditable first pass. It is a prioritization /
indicator, never a resource estimate.

---

## 4. What I built (technical, but readable)

| Component | Detail |
|---|---|
| Ground-truth data | 182 curated, schema-locked, EAS-attested mining districts (US, CA/BC, MX) |
| Volume data | USGS MRDS (Mineral Resource Data System) - 267,964 deposit records used for augmentation |
| Task | Multi-label classification: predict presence of each of 5 metals per location |
| Model | One-vs-rest logistic regression, one model per metal |
| Features | state, deposit type, development status, host rock type, lat/lon (rounded +/-0.1 deg) |
| Evaluation | Leave-one-state-out spatial cross-validation (honest standard for geology - no leakage) |
| Calibration | Sigmoid probability calibration, validated on a strict out-of-region hold-out (CO + CA) |
| Stack | Python / scikit-learn only (no new dependencies) |

Why the methodology matters: in geology, a model that cheats by testing on neighbors of its training
points looks great but is useless. Leave-one-state-out CV forces the model to predict a state it has
never seen, which is the real-world use case (new territory). Reporting that honestly is the
differentiator.

## 5. Honest results

In-region (districts-only leave-one-state-out):

| Metal | Precision | Recall | F1 |
|---|---|---|---|
| Gold | 0.80 | 0.97 | **0.87** |
| Silver | 0.68 | 0.72 | 0.70 |
| Copper | 0.71 | 0.54 | 0.61 |
| Lead | 0.56 | 0.54 | 0.55 |
| Zinc | 0.37 | 0.14 | 0.20 |
| micro-F1 | | | approx 0.66-0.69 |

The honest limits (stated, not hidden):
- Restricting to the 5 predictable metals lifted micro-F1 from 0.52 (64-label attempt) to ~0.66-0.69.
- Rare critical minerals (REE, PGM, uranium, tungsten) are NOT predictable - too few examples to
  generalize. I documented this rather than oversell it.
- Out-of-region calibration is weak (avg Brier 0.29, ECE 0.28): the model is a good ranker but not a
  source of trustworthy absolute probabilities on unseen territory.
- With generic (unknown) geology, even a famous gold district scores low - real geology features are
  required for a meaningful output.
