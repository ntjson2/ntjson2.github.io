MineralFi

MineralFi

  • Category: Web3 Tokenized-Asset Platform
  • Stack: Solidity, Next.js, GraphQL, DynamoDB, IPFS
  • Timeline: Nov 2023 – Present
  • Role: Lead Blockchain & Cloud Engineer

What it does

MineralFi is a platform for tokenizing real-world assets — mineral rights and geospatial investments — as tokens that can be managed by humans and, down the road, by autonomous agents. I built the technical foundation: contracts, APIs, and infrastructure.

What I shipped

  • Smart contracts: Upgradeable MINFI token (ERC-20) and NFTs (ERC-1155) built with OpenZeppelin patterns to handle high-value transactions safely.
  • Incentive systems: NFTs that pay out on milestone achievement for performance-based incentives and stakeholder trusts.
  • Liquidity: Integrated Uniswap V3 for automated liquidity and yield, improving capital efficiency by ~30%.
  • Real-time analytics: Next.js + GraphQL dashboard so investors can track their portfolio live, with data structured for clean queries.
  • Geospatial visuals: 3D maps with Three.js; data on IPFS so what you're viewing is verifiable.
  • Reliable delivery: CI/CD with GitHub Actions and contract testing with Hardhat, substantially reducing production issues.
